# EDTS Project Docs

Agent skill for documenting EDTS iOS and Android projects so both engineers and coding agents can read the docs.

| Skill | What it does |
| --- | --- |
| [`edts-project-docs`](skills/edts-project-docs/) | Generates and maintains `AGENTS.md`, `docs/ARCHITECTURE.md`, module docs, flows, ADRs, a shared `docs/STATUS.md` task list, and (on request) DocC/KDoc comments |

## Install

```sh
npx skills add edtsmobile/edts-project-docs
```

Usage, team workflow, and folder structure: [skills/edts-project-docs/README.md](skills/edts-project-docs/README.md).
